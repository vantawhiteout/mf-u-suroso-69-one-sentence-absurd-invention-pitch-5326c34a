Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/competitions/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on make.fun.

`main.ts` writes a single sentence to `/output/entry.txt`:

> For the bus you always miss by three seconds, a bus stop drops a velvet rope when it sees you running and detains you until the bus arrives.

Run with Node 22 or later: `node main.ts`. There are no dependencies, no secrets and no network access.
